# CS-250-Software-Development-Lifecycle
A repository for including my Sprint Retrospective and Review.

How do I interpret user needs and implement them into a program?
User needs can be interpreted multiple ways. For this project I interpreted user needs via a focus group that let me
hear directly from users the type of features they would want in the SNHU Travel project. From there, I translated 
each need into a user story to develop a backlog. This backlog of user stories could then be picked from by developers
to develop the features that make the application.

How does creating “user stories” help with this?
User stories offer a format in which user needs can be defined. For instance, using the "As a", "I want to", "So that I can"
format allowed me to take a user need and translate what was said into an organic sentence that described the feature.
This could then be iterated on with size, priority, and value statements.

How do I approach developing programs? 
I personally approach developing programs from a quality perspective. This takes the shape of continuous testing, program validation or regression testing. By integrating these practices throughout development, I hope to ensure that the software I produce is reliable, secure, and meets user expectations.

What Agile processes do I hope to incorporate into my future development work?
I would like to incorporate iterative development into future development work as it offers a way to provide continuous
value via feature inclusion instead of a massive monolithic project. I would also like to include Sprint Reviews and
Retrospectives as they offer invaluable insights that can improve the Agile framework I am working in through feedback
and lessons learned.

What does it mean to be a good team member in software development?
To be a good team member, one must know how to communicate and collaborate. This includes offering help as requested 
if you can provide value to your fellow team member. It also involves communicating impediments to the team in 
order to ensure whatever it is that is stopping you from doing work can be addressed. Finally, it also means being
able to coordinate with other team members to make sure you are able to address changes and affirm everyone is on
the same page.
